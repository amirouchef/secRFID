Cours

1. Architecture d'un SDR

Contrairement à une radio classique figée dans ses composants analogiques, un SDR numérise le signal radio le plus tôt possible : antenne → étage RF → convertisseur analogique-numérique (ADC) → tout le reste se fait en logiciel. C'est ce qui rend le NESDR capable de couvrir 100 kHz à 1,75 GHz avec le même matériel.

2. Pourquoi un up-converter ?

Le tuner R820T2 de la clé NESDR ne descend bien en pratique qu'à partir d'environ 24 MHz. Or le RFID LF (125 kHz) et une partie du HF se situent en-dessous. Le Ham It Up Nano (séance 3) résout ce problème en mélangeant le signal reçu avec un oscillateur local fixe (~125 MHz). On ne le branche pas aujourd'hui, mais il faut comprendre pourquoi il existe avant de l'utiliser.

3. Rôle du TCXO

Un oscillateur à quartz standard dérive avec la température. Le TCXO (Temperature Compensated Crystal Oscillator) compense cette dérive.

4. Logiciels SDR

SDR# (Windows), GQRX (Linux/Mac) et SDR++ (multiplateforme) affichent tous le spectre et le waterfall, permettent de régler le gain, et d'appliquer un décalage de fréquence.

Atelier — sans up-converter

Objectif : installer le logiciel SDR et valider que la clé NESDR fonctionne, avant de complexifier le montage la semaine prochaine.

Matériel : clé NESDR Smart V5, kit antenne VHF-UHF, PC.

Étape 1 : identifier le matériel

Posez la clé NESDR et le kit antenne VHF-UHF devant vous. En cas de doute, comparez avec la page Matériel.

Étape 2 : installer le logiciel SDR

SDR# (Airspy SDR# Studio) — procédure validée :

  1. Télécharger le « Software Defined Radio Package » sur airspy.com/download et le décompresser.
  2. Brancher la clé NESDR, puis lancer install-rtlsdr.bat (il crée zadig.exe).
  3. Lancer Zadig → Options → List All Devices → sélectionner NESDR Smart V5 → Install Driver.
  4. Lancer SDRSharp.dotnet8.exe.

SDR++ (alternative) : github.com/AlexandreRouma/SDRPlusPlus (release « nightly », canal standard de ce projet). Évitez GQRX sur Windows, support encore expérimental.

Si le logiciel ne s'installe pas : vérifiez les droits administrateur ; sur certains postes d'établissement, l'installation peut nécessiter le service informatique.

Étape 3 : brancher l'antenne directement

Branchez le kit antenne VHF-UHF directement sur la clé NESDR — sans up-converter, c'est la bonne antenne pour cette plage.

Étape 4 : capter une station FM

Sélectionnez la clé NESDR comme source, passez en mode WFM, cherchez une station entre 88 et 108 MHz.

✓ Résultat attendu : audio clair et pic net sur le spectre à la fréquence de la station.

Si rien n'apparaît : essayez un autre port USB, et sur Windows revérifiez le driver Zadig (étape 2).

Livrable : capture d'écran d'une station FM clairement reçue, avec le nom du logiciel utilisé
